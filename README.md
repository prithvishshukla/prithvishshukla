## 🚀 Featured Projects

### 🔍 Tracewise | Developer Intelligence Platform

**Know what changed. Know what breaks.**

Tracewise is a developer intelligence platform designed to detect changes in third-party APIs and identify potentially affected areas of a codebase.

The goal is to help developers understand the impact of external API changes before those changes turn into unexpected bugs or broken integrations.

#### Key Features

* 🔎 **API Change Detection:** Track changes in third-party API documentation, SDK feeds, and OpenAPI specifications.
* 🧩 **Codebase Analysis:** Scan JavaScript, TypeScript, and Python projects for relevant API usage.
* 🎯 **Impact Analysis:** Connect detected API changes to potentially affected files and call sites.
* 🚦 **Severity Classification:** Organize findings by severity, confidence, and supporting evidence.
* 📊 **Centralized Dashboard:** Manage repositories, API changes, and impact findings in one place.
* ⚙️ **Background Processing:** Handle asynchronous tasks, retries, and job deduplication.

#### Tech Stack

`TypeScript` `Next.js` `React` `Tailwind CSS` `Fastify` `PostgreSQL` `Drizzle ORM` `Redis` `BullMQ` `Docker` `Vitest`

**Focus Areas:** Developer Experience, Static Analysis, API Monitoring, Background Processing, and Code Intelligence.
